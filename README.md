# Minibox — Static Demo (Original UI)

A static mirror of the **Minibox Barbershop Management System** (Laravel 12),
rendered from the original application itself — same Blade views, same Soft UI
Dashboard styling, same assets, and the app's own sample data — so the demo
looks and navigates exactly like the real thing. Forms that would need the
server are intercepted with a demo notice; table search filters work
client-side.

- Live demo: https://portofolio-hasbi.web.id/minibox-demo/
- Original application: https://github.com/Hasbi1605/inventaris-minibox

Pages mirrored from the running app: Dashboard, Kelola Transaksi, Kelola
Inventaris, Kelola Layanan, Kelola Pengeluaran, Kelola Cabang, Kelola Kapster,
Kelola Kategori, Laporan — including each section's create/edit forms.

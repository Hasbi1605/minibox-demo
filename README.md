# Minibox — Front-End Demo (Static)

An interactive front-end demo of the **Minibox Barbershop Management System**
(originally Laravel 12), built for portfolio purposes. All data is dummy data
stored locally in the visitor's browser (localStorage) — create, edit, and
delete operations work entirely on the client.

- Live demo: https://portofolio-hasbi.web.id/minibox-demo/
- Original application (Laravel): https://github.com/Hasbi1605/inventaris-minibox

Views: Dashboard (today's revenue, transactions, monthly expenses, low-stock
alerts), Transaksi, Layanan, Inventaris, Pengeluaran. Data shapes mirror the
original app's schema.

Files in `docs/` (GitHub Pages source): `index.html`, `style.css`, `app.js`.
